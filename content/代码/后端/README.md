> 服务端相关：接口开发、权限、选型。判定标准是**进程跑在服务端**，所以用 TypeScript 写的 Nest 也在这里。

## 目录

| 目录 | 内容 | 文档数 |
| --- | --- | --- |
| [java](java/) | Java 环境与 VSCode 配置 | 1 |
| [php](php/) | ThinkPHP 写接口、根据权限添加页面（官方后台）、小玩意 | 3 |
| [node](node/) | Node 后端入门、HTTP/REST、Express、NestJS、数据库与安全 | 8 |

## 说明

- **Nest** 放在 `node/` 下：它是 Node 生态的服务端框架，语言与前端相同，但运行在服务端、对外提供 API。
- 前端构建工具链（vite / webpack / 包管理）不在这里，见 `前端/工程化`、`前端/node`。
- 部署、服务器、Docker 相关见 `系统与运维`。
