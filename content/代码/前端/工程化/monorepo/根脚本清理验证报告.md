> 验证日期：2026-11-19

## 1. 清理目标

| 旧脚本 | 处理 | 替代 |
| --- | --- | --- |
| `install:all` | 删除 | 根 `npm install` / `npm ci` |
| `docs:dev` | 删除 | `dev:vp` |
| `docs:build` | 删除 | `build:vp` |
| `docs:preview` | 删除 | `preview:vp` |
| `create:docs` / `create:herscheliu` | 删除 | 脚手架模块整体移除 |

当前根脚本：

```json
{
  "dev:vp": "npm --workspace apps/vitepress run dev --",
  "build:vp": "npm --workspace apps/vitepress run build",
  "preview:vp": "npm --workspace apps/vitepress run preview --",
  "dev:astro": "npm --workspace apps/astro run dev --",
  "build:astro": "npm --workspace apps/astro run build",
  "preview:astro": "npm --workspace apps/astro run preview --",
  "normalize": "node scripts/normalize-frontmatter.mjs ./content",
  "pages:build": "..."
}
```

`install:all` 没有存在的必要：根目录执行 `npm install` 就是安装全部 workspace。

## 2. 残留引用扫描

扫描命令：

```bash
grep -RIn \
  --exclude-dir=node_modules \
  --exclude-dir=dist \
  --exclude-dir=.astro \
  --exclude-dir=.pages \
  --exclude-dir=.git \
  'docs:dev\|docs:build\|docs:preview\|install:all\|create-study-notes' \
  README.md content package.json .github apps scripts
```

结果：

- 根 `package.json`：无 `docs:*`、`install:all`、`create:*`；
- `.github/workflows/deploy.yml`：只使用 `build:vp`、`build:astro`、`pages:build`；
- `scripts/`：只有 `normalize-frontmatter.mjs`；
- `apps/`：没有引用根 `docs:*`；
- `content/` 中唯一出现 `docs:dev` 的位置是独立的 VitePress 示例笔记 `代码/前端/vue/vite+vue3.0/vitePress.md`，它描述的是另一个项目的 `package.json`，不是本仓库根脚本；
- `create-study-notes` 包和引用已删除。

结论：**当前项目无残留依赖、无隐式调用、无 CI 对 `docs:*` / `install:all` 的依赖。**

### 3.6 CI 链路模拟

实际 workflow：

```yaml
- run: npm ci
- run: npm run build:vp
  env:
    DOCS_BASE: /studyNotes/vitepress/
- run: npm run build:astro
  env:
    ASTRO_BASE: /studyNotes/astro/
- run: npm run pages:build
- uses: actions/upload-pages-artifact@v3
  with:
    path: .pages
```

本地按相同顺序执行，全部通过。
