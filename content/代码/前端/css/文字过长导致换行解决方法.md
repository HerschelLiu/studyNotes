---
title: "文字过长导致换行解决方法"
---

> 两种「长文本溢出」场景，对应的 CSS 不一样。

## 英文单词过长：允许在单词内换行

```css
.word-break {
  word-wrap: break-word;   /* 等价于 overflow-wrap: break-word */
  word-break: break-all;   /* 需要更激进地在任意字符处断行时加这行 */
}
```

## 中文过长：单行省略号

```css
.ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

## 多行省略号（补充）

```css
.ellipsis-2 {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;   /* 行数 */
  overflow: hidden;
}
```
