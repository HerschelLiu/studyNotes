> 一套「表格 + 工具条 + 列声明插槽」的封装，由三部分组成：
>
> | 部分 | 作用 |
> | --- | --- |
> | `RightToolbar` | 右侧工具条：显隐列、刷新、搜索开合 |
> | `TableToolbar` | 表格顶部工具条：新建 / 批量 / 导入导出等按钮 + 列显隐 |
> | `CompTable` | 表格主体：列配置注入、格式化、树形、合并单元格、列显隐持久化 |
>
> **源码位置**：`CompTable/` 目录下 17 个组件文件，另附共享工具 `utils/selectionKey.ts`；`CompBaseTable/` 内再按 `columns/`、`selection/`、`composables/` 分组（P0-1：勾选态外置的多选实现；本文档下方代码块与这些文件逐字一致）。
> 另有一份 Element Plus 原生 `type="selection"` 的对照实现：`CompTable-EP原生多选/`（P0-2），差异与实测见「[多选方案对比](#多选方案对比)」。
> `RightToolbar` / `TableToolbar` 的源码属于项目 `src/components`，不在本仓库，仅作对照。

## RightToolbar

`index.vue`

```vue
<template>
  <div
    class="top-right-btn"
    :style="style">
    <el-row>
      <el-tooltip
        class="item"
        effect="dark"
        :content="showSearch ? '隐藏搜索' : '显示搜索'"
        placement="top"
        v-if="search">
        <el-button
          circle
          icon="Search"
          @click="toggleSearch()" />
      </el-tooltip>
      <el-tooltip
        class="item"
        effect="dark"
        content="刷新"
        placement="top">
        <el-button
          circle
          icon="Refresh"
          @click="refresh()" />
      </el-tooltip>
      <el-tooltip
        class="item"
        effect="dark"
        content="显隐列"
        placement="top"
        v-if="Object.keys(columns).length > 0">
        <el-button
          circle
          icon="Menu"
          @click="showColumn()"
          v-if="showColumnsType == 'transfer'" />
        <el-dropdown
          trigger="click"
          :hide-on-click="false"
          style="padding-left: 12px"
          placement="bottom-end"
          :max-height="200"
          v-if="showColumnsType == 'checkbox'">
          <el-button
            circle
            icon="Menu" />
          <template #dropdown>
            <el-dropdown-menu>
              <!-- 全选/反选 按钮 -->
              <el-dropdown-item>
                <el-checkbox
                  :indeterminate="isIndeterminate"
                  v-model="isChecked"
                  @change="toggleCheckAll">
                  列展示
                </el-checkbox>
              </el-dropdown-item>
              <div class="check-line"></div>
              <template
                v-for="(item, key) in columns"
                :key="item.key">
                <el-dropdown-item :divided="Number(key) === 0">
                  <el-checkbox
                    v-model="item.visible"
                    @change="checkboxChange($event, key)"
                    :label="item.label" />
                </el-dropdown-item>
              </template>
            </el-dropdown-menu>
          </template>
        </el-dropdown>
      </el-tooltip>
    </el-row>
    <el-dialog
      :title="title"
      v-model="open"
      append-to-body>
      <el-transfer
        :titles="['显示', '隐藏']"
        v-model="value"
        :data="transferData"
        @change="dataChange"></el-transfer>
    </el-dialog>
  </div>
</template>

<script setup lang="ts">
  import cache from '@/plugins/cache'
  import type { TableShowColumns } from '@/types/api/common'

  const props = defineProps({
    /* 是否显示检索条件 */
    showSearch: {
      type: Boolean,
      default: true
    },
    /* 显隐列信息（数组格式、对象格式） */
    columns: {
      type: [Array, Object],
      default: () => ({})
    },
    /* 是否显示检索图标 */
    search: {
      type: Boolean,
      default: true
    },
    /* 显隐列类型（transfer穿梭框、checkbox复选框） */
    showColumnsType: {
      type: String,
      default: "checkbox"
    },
    /* 右外边距 */
    gutter: {
      type: Number,
      default: 10
    },
    /* 列显隐状态记忆的 localStorage key（传入则启用记忆，不传则不记忆） */
    storageKey: {
      type: String,
      default: ""
    }
  })

  const emits = defineEmits(['update:showSearch', 'queryTable'])

  // 显隐数据
  const value = ref<number[]>([])
  // 弹出层标题
  const title = ref("显示/隐藏")
  // 是否显示弹出层
  const open = ref(false)

  const style = computed(() => {
    const ret: Record<string, string> = {}
    if (props.gutter) {
      ret.marginRight = `${props.gutter / 2}px`
    }
    return ret
  })

  // 是否全选/半选 状态
  const isChecked = computed({
    get: () => Array.isArray(props.columns) ? props.columns.every((col: TableShowColumns) => col.visible) : Object.values(props.columns).every((col) => (col as TableShowColumns).visible),
    set: () => {}
  })
  const isIndeterminate = computed(() => Array.isArray(props.columns) ? props.columns.some((col: TableShowColumns) => col.visible) && !isChecked.value : Object.values(props.columns).some((col) => (col as TableShowColumns).visible) && !isChecked.value)
  const transferData = computed(() => Array.isArray(props.columns) ? props.columns.map((item: any, index: number) => ({ key: index, label: item.label })) : Object.keys(props.columns).map((key, index) => ({ key: index, label: (props.columns as any)[key].label })))

  // 搜索
  const { proxy } = getCurrentInstance()!
  function toggleSearch(): void {
    let el: HTMLElement | null = proxy!.$el
    let formEl: HTMLElement | null = null
    while ((el = el!.parentElement) && el !== document.body) {
      if ((formEl = el.querySelector('.el-form'))) break
    }
    if (!formEl) return emits('update:showSearch', !props.showSearch)
    // 优先动画整个 search-wrapper（el-card），避免表单先消失、卡片后消失的两段式抖动
    const targetEl = formEl.closest('.search-wrapper') as HTMLElement | null
    animateSearch(targetEl || formEl, props.showSearch)
  }
  function animateSearch(el: HTMLElement, isHide: boolean): void {
    const DURATION = 260
    const TRANSITION = 'max-height 0.25s ease, opacity 0.2s ease'
    const clear = () => Object.assign(el.style, { transition: '', maxHeight: '', opacity: '', overflow: '' })
    Object.assign(el.style, { overflow: 'hidden', transition: '' })
    if (isHide) {
      Object.assign(el.style, { maxHeight: el.scrollHeight + 'px', opacity: '1', transition: TRANSITION })
      requestAnimationFrame(() => Object.assign(el.style, { maxHeight: '0', opacity: '0' }))
      setTimeout(() => { emits('update:showSearch', false); clear() }, DURATION)
    } else {
      emits('update:showSearch', true)
      nextTick(() => {
        Object.assign(el.style, { maxHeight: '0', opacity: '0' })
        requestAnimationFrame(() => requestAnimationFrame(() => {
          Object.assign(el.style, { transition: TRANSITION, maxHeight: el.scrollHeight + 'px', opacity: '1' })
        }))
        setTimeout(clear, DURATION)
      })
    }
  }
  // 刷新
  function refresh(): void {
    emits("queryTable")
  }

  // 右侧列表元素变化
  function dataChange(data: any[], _direction?: string, _movedKeys?: any[]): void {
    if (Array.isArray(props.columns)) {
      for (let item in props.columns) {
        const key = props.columns[item].key
        props.columns[item].visible = !data.includes(parseInt(key))
      }
    } else {
      Object.keys(props.columns).forEach((key, index) => {
        props.columns[key].visible = !data.includes(index)
      })
    }
    saveStorage()
  }

  // 打开显隐列dialog
  function showColumn(): void {
    open.value = true
  }

  // 如果传入了 storageKey，从 localStorage 恢复列显隐状态
  if (props.storageKey) {
    try {
      const saved = cache.local.getJSON(props.storageKey)
      if (saved && typeof saved === 'object') {
        if (Array.isArray(props.columns)) {
          props.columns.forEach((col: TableShowColumns, index: number) => {
            // 数组元素带 key 时按 key 恢复（CompTable 列路径），否则按数组下标
            const stateKey = (col as TableShowColumns & { key?: string }).key ?? index
            if (saved[stateKey] !== undefined) col.visible = saved[stateKey]
          })
        } else {
          Object.keys(props.columns).forEach(key => {
            if (saved[key] !== undefined) props.columns[key].visible = saved[key]
          })
        }
      }
    } catch (e) {}
  }
  if (props.showColumnsType == "transfer") {
    // transfer穿梭显隐列初始默认隐藏列
    if (Array.isArray(props.columns)) {
      for (let item in props.columns) {
        if (props.columns[item].visible === false) {
          value.value.push(parseInt(item))
        }
      }
    } else {
      Object.keys(props.columns).forEach((key, index) => {
        if (props.columns[key].visible === false) {
          value.value.push(index)
        }
      })
    }
  }

  // 单勾选
  function checkboxChange(event: any, key: string | number): void {
    if (Array.isArray(props.columns)) {
      // key 是 v-for 的索引，直接按索引定位
      const idx = Number(key)
      const col = props.columns[idx]
      if (col) {
        col.visible = event
      }
    } else {
      ;(props.columns as any)[key].visible = event
    }
    saveStorage()
  }

  // 切换全选/反选
  function toggleCheckAll(): void {
    const newValue = !isChecked.value
    if (Array.isArray(props.columns)) {
      props.columns.forEach((col: TableShowColumns) => (col.visible = newValue))
    } else {
      Object.values(props.columns).forEach((col) => ((col as TableShowColumns).visible = newValue))
    }
    saveStorage()
  }

  // 将当前列显隐状态持久化到 localStorage
  function saveStorage(): void {
    if (!props.storageKey) return
    try {
      let state: { [key: string]: boolean } = {}
      if (Array.isArray(props.columns)) {
        // 数组元素带 key 时按 key 存储（CompTable 列路径），否则按数组下标
        props.columns.forEach((col: TableShowColumns, index: number) => { state[(col as TableShowColumns & { key?: string }).key ?? index] = col.visible })
      } else {
        Object.keys(props.columns).forEach(key => { state[key] = props.columns[key].visible })
      }
      cache.local.setJSON(props.storageKey, state)
    } catch (e) {}
  }
</script>

    display: block;
    margin-left: 0px;
  }
  :deep(.el-transfer__button:first-child) {
    margin-bottom: 10px;
  }
  :deep(.el-dropdown-menu__item) {
    line-height: 30px;
    padding: 0 17px;
  }
</style>
```

## TableToolbar

`index.vue`

```vue
<template>
  <el-row
    :gutter="10"
    class="mb8">
    <!-- 前置自定义按钮 -->
    <slot name="prefix"></slot>

    <!-- 配置驱动的按钮组 -->
    <!-- v-hasPermi="btn.perm ? [btn.perm] : []" -->
    <template
      v-for="btn in visibleButtons"
      :key="btn.key">
      <el-col
        :span="1.5"
        style="margin:0px 0 8px 0;">
        <el-button
          v-hasPermi="btn.perm ? [btn.perm] : []"
          :type="resolveType(btn)"
          :plain="btn.plain !== false"
          :icon="resolveIcon(btn)"
          :size="btn.size || 'default'"
          :disabled="btn.disabled"
          @click="onClick(btn)">
          {{ resolveLabel(btn) }}
        </el-button>
      </el-col>
    </template>

    <!-- 后置自定义按钮 -->
    <slot></slot>

    <!-- 右侧工具栏（搜索开关/刷新/显隐列） -->
    <right-toolbar
      v-if="props.showRightToolbar"
      v-model:showSearch="innerShowSearch"
      :columns="props.columns"
      :search="props.showColumnSetting"
      :gutter="props.gutter"
      :storageKey="props.storageKey"
      @queryTable="emit('queryTable')"></right-toolbar>

    <!-- right-toolbar 之后的额外内容 -->
    <slot name="extra"></slot>
  </el-row>
</template>

<script setup lang="ts">
  import { computed } from "vue";
  import type {
    TableToolbarProps,
    TableToolbarEmits,
    ToolbarButton,
  } from "./types";
  import { DEFAULT_BUTTON_PRESET } from "./types";

  const props = withDefaults(defineProps<TableToolbarProps>(), {
    buttons: () => [],
    showRightToolbar: true,
    showSearch: true,
    gutter: 10,
    showColumnSetting: true,
  });

  const emit = defineEmits<TableToolbarEmits>();

  // 过滤隐藏按钮
  const visibleButtons = computed(() =>
    props.buttons.filter((b) => !b.hidden),
  );

  // showSearch 双向绑定
  const innerShowSearch = computed({
    get: () => props.showSearch,
    set: (val) => emit("update:showSearch", val),
  });

  // 解析按钮文案/类型/图标：优先用配置，否则回退到内置默认
  const resolveLabel = (btn: ToolbarButton) =>
    btn.label ?? DEFAULT_BUTTON_PRESET[btn.key]?.label ?? btn.key;

  const resolveType = (btn: ToolbarButton) =>
    btn.type ?? DEFAULT_BUTTON_PRESET[btn.key]?.type ?? "primary";

  const resolveIcon = (btn: ToolbarButton) =>
    btn.icon ?? DEFAULT_BUTTON_PRESET[btn.key]?.icon ?? "";

  const onClick = (btn: ToolbarButton) => {
    emit("action", btn.key, btn);
  };
</script>
```

`types.ts`

```ts
import type { Component } from "vue";

/** 内置按钮语义，覆盖项目里最常见的工具栏操作 */
export type ToolbarActionKey =
    | "add"
    | "edit"
    | "del"
    | "batch"
    | "import"
    | "export"
    | "download"
    | string;

/** 单个工具栏按钮配置 */
export interface ToolbarButton {
    /** 动作标识，点击后随 action 事件回传（如 'add' / 'export'），也用于匹配内置默认样式 */
    key: ToolbarActionKey;
    /** 按钮文案；不传则取内置默认（如 add -> "新增"） */
    label?: string;
    /** el-button 的 type；不传则取内置默认 */
    type?: "primary" | "success" | "warning" | "danger" | "info" | "";
    /** 按钮图标名（Element Plus 图标组件名，如 'Plus'）或图标组件；不传则取内置默认 */
    icon?: string | Component;
    /** 是否 plain 风格，默认 true（对齐项目现状） */
    plain?: boolean;
    /** 按钮尺寸，默认 'default' */
    size?: "large" | "default" | "small";
    /** 是否禁用 */
    disabled?: boolean;
    /** 是否隐藏该按钮（用于按权限/状态动态控制） */
    hidden?: boolean;
    /** 权限标识，透传给 v-hasPermi 指令（旧范式常用），为空则不加限制 */
    perm?: string;
}

export interface TableToolbarProps {
    /** 按钮配置数组，按顺序渲染 */
    buttons?: ToolbarButton[];
    /** 是否显示右侧 right-toolbar（搜索开关/刷新/显隐列），默认 true */
    showRightToolbar?: boolean;
    /** 搜索区显隐状态，配合 v-model:showSearch */
    showSearch?: boolean;
    /** 透传给 right-toolbar 的列显隐配置 */
    columns?: any[] | Record<string, any>;
    /** right-toolbar 的右外边距 gutter，默认 10 */
    gutter?: number;
    /** right-toolbar 列显隐状态本地存储 key */
    storageKey?: string;
    /** 是否显示 right-toolbar 内的显隐列/搜索开关图标（透传 search），默认 true */
    showColumnSetting?: boolean;
}

export interface TableToolbarEmits {
    /** 点击任一按钮，回传该按钮的 key（如 'add' / 'export'） */
    (e: "action", key: ToolbarActionKey, button: ToolbarButton): void;
    /** 搜索区显隐切换，配合 v-model:showSearch */
    (e: "update:showSearch", value: boolean): void;
    /** right-toolbar 刷新按钮点击，等价于原 @queryTable */
    (e: "queryTable"): void;
}

/** 内置按钮的默认样式映射（label / type / icon） */
export const DEFAULT_BUTTON_PRESET: Record<
    string,
    { label: string; type: ToolbarButton["type"]; icon: string }
> = {
    add: { label: "新增", type: "primary", icon: "Plus" },
    edit: { label: "修改", type: "success", icon: "Edit" },
    del: { label: "删除", type: "danger", icon: "Delete" },
    batch: { label: "批量删除", type: "danger", icon: "Delete" },
    import: { label: "导入", type: "info", icon: "Upload" },
    export: { label: "导出", type: "success", icon: "Upload" },
    download: { label: "下载模板", type: "warning", icon: "Tickets" },
};

```

| --- | --- | --- |
| EP 自定义层 | `CompBaseTable/` | 否（只用 `@/utils/selectionKey`、`@/hooks/useFormatValue`、`@/hooks/useRules`、`@/hooks/useTable`、`@/components/Price`） |
| 若依工具栏积木 | `Toolbar/` + `@/components/TableToolbar` + `@/components/RightToolbar` | 是 |
| 若依显隐列积木 | `ColumnVisibility/` | 是 |
| 若依拼装层 | `index.vue`（默认 `CompTable`） | 是 |

> **默认导出 `CompTable` = 拼装层**，现有页面（`import CompTable from '@/components/CompTable/index.vue'`、`v-model:list`、`v-model:selected`、`#toolbar`、`storage-key` 等）不需要修改。
>
> **`useCompTable()` 返回的 `CompBaseTable` 是 EP 层**（不含工具栏 / 显隐）；现有页面只用它返回的 `CompTableColumn`，所以不受影响。
>
> `CompBaseTable` 的列来源有两种：
> 1. 默认读 `useCompTable(columns, key)` 注入的列
> 2. 直接传 `:columns="columns"`

```ts
import type { VNode } from 'vue'
import type { RuleValue } from '@/hooks/useRules'
import type { TableColumnCtx } from 'element-plus'
import type { DefaultRow, SummaryMethod, TableProps, TreeProps } from 'element-plus/es/components/table/src/table/defaults'
import type { Props as CompPriceProps } from '@/components/Price/index.vue'
import type { DictList, EnumObject } from '@/hooks/useFormatValue'

/** 单元格插槽作用域（Element Plus default 插槽） */
export interface CellScope<R extends Record<string, any>> {
  row: R
  column: TableColumnCtx<R>
  $index: number
}

/** 表头插槽作用域（Element Plus header 插槽） */
export interface HeaderScope<R extends Record<string, any>> {
  column: TableColumnCtx<R>
  $index: number
}

/** CompBaseTable（EP 自定义层）插槽定义 */
export interface BaseCompTableSlots<R extends Record<string, any>> {
  /** 列声明插槽：承载 <CompTableColumn> 标记，由 CompBaseTable 读取其中的 #header / #default，不直接渲染 */
  default?: () => any
  /** 通用工具栏插槽：若依层放 TableToolbar，非若依项目可放任意按钮 */
  toolbar?: () => any
  /** 静态展开列内容插槽，传入后自动渲染 type=expand 列 */
  expand?: (props: { row: R; $index: number }) => any
}

/** 列格式化配置（驱动 useFormatValue，按类型约束 formatStr） */
export type TableColumnFormat =
  | { type: 'boolean' | 'date'; formatStr?: string }
  | { type: 'enum'; formatStr: EnumObject }
  | { type: 'dict'; formatStr: DictList }

/** 单元格合并方法（el-table span-method） */
export type TableSpanMethod = NonNullable<TableProps<any>['spanMethod']>

/** 表格高度策略 */
export type TableHeightMode =
  /** 固定为视口剩余高度（默认），不随内容滚动 */
  | 'fixed'
  /** 以视口剩余高度为上限，内容少时收缩 */
  | 'max'
  /** 不限制高度，随内容自然撑开 */
  | 'auto'

type PriceConfig = Omit<CompPriceProps, 'price'>

/** 单列配置 */
export interface TableColumn<T> {
  /** 唯一标识（prop 重复时必须传），兼作 localStorage 显隐 key */
  key?: string
  /**
   * 数据字段名
   * - 默认按 T 的键校验；'index' 为序号列（type=index），'expand' 为展开列（type=expand），'action' 为操作列
   * - `custom-` 前缀为自定义列不做 T 键校验
   */
  prop: keyof T | 'action' | 'index' | 'expand' | `custom-${string}`
  /** 列标题 */
  label: string
  /** 多级表头子列：存在时渲染为分组表头，自身不绑定数据字段 */
  children?: TableColumn<T>[]
  /** 固定宽度 */
  width?: string | number
  /** 最小宽度，不传时使用表格级 minWidth 兜底 */
  minWidth?: string | number
  /** 固定列 */
  fixed?: boolean | 'left' | 'right'
  /** 对齐方式 */
  align?: 'left' | 'center' | 'right'
  /** 表头对齐方式（不传则跟随 align） */
  headerAlign?: 'left' | 'center' | 'right'
  /** 内容溢出 tooltip */
  showOverflowTooltip?: TableColumnCtx<any>['showOverflowTooltip']
  /** 自定义表头渲染：传函数直接用作 render-header；传 true 则由 CompTable 自动渲染必填红星 */
  renderHeader?: ((scope: any) => VNode) | true
  /** useFormatValue 格式化配置；与 price 互斥 */
  format?: TableColumnFormat
  /** 默认是否显示，用于列显隐工具栏中 */
  visible?: boolean
  /** true → 价格列，自动用 CompPrice 格式化金额；与 format 互斥 */
  price?: boolean
  /** CompPrice 配置项，仅当 price=true 时生效 */
  priceConfig?: PriceConfig
  /** true → 彻底不渲染该列，且不出现在列显隐工具栏中（功能关闭/预留列），用户无法开启 */
  disabled?: boolean
}

/** 表格数据：数组，或带 items / loading 的对象（若依 List<T, R> 可直接传入） */
export type TableData<T, R> = R[] | { items: R[]; loading?: boolean; total?: number }

interface TableDataProps<T, R> {
  /** 数据列表：数组或 { items, loading } 对象 */
  list: TableData<T, R>
  /** 数组模式的加载态；对象模式读取 list.loading */
  loading?: boolean
}

interface TableSelectionProps<R> {
  /** 跨页已选数据 */
  selected?: R[]
  /** 主键字段，复合主键用 '-' 连接（如 'id'、'id-type'） */
  keys?: string
  /** 是否启用选择列 */
  selectable?: boolean
  /** 选择列宽度，默认 55 */
  selectionWidth?: ID
}

interface TableColumnProps<R> {
  /** 多表区分 key，对应 useCompTable(columns, key) 的第二个参数 */
  tableKey?: string
  /** 渲染列：不传时读取 useCompTable 注入的列；非若依项目可直接传 */
  columns?: TableColumn<R>[]
  /** 序号列配置覆盖，不传时从 columns 中找 prop='index' */
  indexColumnConfig?: TableColumn<R>
  /** 展开列配置覆盖，不传时从 columns 中找 prop='expand' */
  expandColumnConfig?: TableColumn<R>
  /** 列最小宽度，默认 100 */
  minWidth?: ID
  /** 单元格水平对齐（全局默认，列 col.align 优先） */
  align?: 'left' | 'center' | 'right'
  /** 表头水平对齐（全局默认，列 col.headerAlign 优先） */
  headerAlign?: 'left' | 'center' | 'right'
  /** 表头必填红星配置（配合 column.renderHeader=true） */
  required?: boolean | Record<string, RuleValue>
  /**
   * 同一 prop 出现多个 <CompTableColumn> 声明时的处理方式：
   * - 'override'（默认）：后声明的覆盖先声明的
   * - 'merge'：按声明顺序合并渲染（如内置操作列 + 消费方操作列）
   */
  columnSlotMode?: 'merge' | 'override'
}

interface TableLayoutProps<R extends DefaultRow> {
  /** 高度策略，默认 'fixed' */
  heightMode?: TableHeightMode
  /** 显式高度，传入后直接使用，不参与视口计算 */
  height?: number
  /** 高度上限，仅 heightMode='max' 时生效 */
  maxHeight?: number
  /** 底部预留高度兜底值 */
  bottomOffset?: number
  /** 表格尺寸（el-table size） */
  size?: TableProps<any>['size']
  /** 是否显示合计行，默认 false */
  showSummary?: boolean
  /** 合计行计算方法 */
  summaryMethod?: SummaryMethod<R>
  /** 合并行或列（el-table span-method） */
  spanMethod?: TableSpanMethod
  /** 是否显示序号 */
  index?: boolean
  /** 是否默认展开所有行 */
  defaultExpandAll?: boolean
  /** 树形表格子节点映射（el-table tree-props） */
  treeProps?: TreeProps
  /** 树形表格行唯一标识（el-table row-key）。不传时回退 keys */
  rowKey?: TableProps<any>['rowKey']
}

interface TableCellProps {
  /** 自定义单元格插槽是否包一层渲染组件（默认 true），让编辑态只重渲染当前单元格 */
  isolateCellSlots?: boolean
}

/** EP 自定义表格（CompBaseTable）的 props，按数据 / 选择 / 列 / 布局 / 单元格分组 */
export interface BaseCompTableProps<T, R extends DefaultRow>
  extends TableDataProps<T, R>,
    TableSelectionProps<R>,
    TableColumnProps<R>,
    TableLayoutProps<R>,
    TableCellProps {}
```

> EP 层类型：`TableColumn` / `BaseCompTableProps` / `BaseCompTableSlots` / `TableData`。
> 对外类型在 `CompTable/types.ts` 里转出并扩展。

> `columnSlotMode`：同一 `prop` 有多个 `<CompTableColumn>` 声明时，`override`（默认）后者覆盖前者，`merge` 按声明顺序合并渲染（CompSelect 用它把内置选择按钮与消费方操作列合并）。

```ts
  },
  setup(props) {
    return () => {
      const rowKeys = props.rowKeys
      let checkedCount = 0
      for (const rowKey of rowKeys) {
        if (props.state.get(rowKey)) checkedCount++
      }
      return h(ElCheckbox, {
        modelValue: rowKeys.length > 0 && checkedCount === rowKeys.length,
        indeterminate: checkedCount > 0 && checkedCount < rowKeys.length,
        disabled: rowKeys.length === 0,
        'onUpdate:modelValue': (checked: CheckboxValueType) => {
          if (typeof checked === 'boolean') props.onToggleAll(checked)
        }
      })
    }
  }
})
```

> 关键点：**复选框必须在自己的组件里读勾选态**。
> 如果直接写 `<el-checkbox :model-value="state.get(key)">` 在 `CompTable` 模板里，读 `state` 的会是表格渲染 effect，
> 勾选任意一行都会触发整表重渲染；拆成子组件后，依赖只落在该复选框自己的 render effect 上。

### CompBaseTable/selection/useCompTableSelection.ts

```ts
import type { ComputedRef } from 'vue'

import { reactive, computed, watch } from 'vue'

import { deleteSelectedList, putSelectedList, rowKeyOf, splitKeys } from '@/utils/selectionKey'

interface Options<R extends Record<string, any>> {
  getKeys: () => string
  getSelected: () => R[]
  /** 含树形子行，用于同步勾选态 */
  getRows: () => R[]
  /** 全选范围：树形表只选顶层行 */
  getCheckableRows: () => R[]
  onSelectedChange: (rows: R[]) => void
}

/**
 * 勾选态不写 row.checked：el-table 对 data 深监听，写行数据会整表重渲染。
 * 主键去重 / 差集复用 @/utils/selectionKey。
 */
export const useCompTableSelection = <R extends Record<string, any>>({
  getKeys,
  getSelected,
  getRows,
  getCheckableRows,
  onSelectedChange
}: Options<R>) => {
  const fields = computed(() => splitKeys(getKeys()))

  /** 未传 keys 时用行对象身份生成 key，保证各行独立 */
  const fallbackKeys = new WeakMap<object, string>()
  let fallbackSeed = 0

  const keyOf = (row: R) => {
    if (fields.value.length) return rowKeyOf(row, fields.value)
    let key = fallbackKeys.get(row)
    if (!key) {
      key = `row-${++fallbackSeed}`
      fallbackKeys.set(row, key)
    }
    return key
  }

  const state = reactive(new Map<string, boolean>())

  const checkableRows = computed(() => getCheckableRows().filter(row => !row.disabled))
  const checkableKeys: ComputedRef<string[]> = computed(() => checkableRows.value.map(row => keyOf(row)))

  /** 外部清空 selected / 跨页返回 / 数据刷新时同步当前页勾选态 */
  const syncFromSelected = () => {
    const rows = getRows()
    const selectedKeys = new Set(getSelected().map(row => keyOf(row)))
    rows.forEach(row => {
      const key = keyOf(row)
      const checked = selectedKeys.has(key)
      if (state.get(key) !== checked) state.set(key, checked)
    })
    // 已离开当前页的 key 不再保留，避免跨页访问后状态无限累积
    const pageKeys = new Set(rows.map(row => keyOf(row)))
    for (const key of [...state.keys()]) {
      if (!pageKeys.has(key)) state.delete(key)
    }
  }

  watch([fields, () => getRows(), () => getSelected()], syncFromSelected, { immediate: true })

  const commit = (rows: R[]) => onSelectedChange(rows)

  const toggle = (row: R, checked: boolean) => {
    const rowKey = keyOf(row)
    state.set(rowKey, checked)
    commit(checked ? putSelectedList(getSelected(), [row], getKeys()) : deleteSelectedList(getSelected(), [row], getKeys()))
  }

  const toggleAll = (checked: boolean) => {
    const rows = checkableRows.value
    rows.forEach(row => state.set(keyOf(row), checked))
    commit(checked ? putSelectedList(getSelected(), rows, getKeys()) : deleteSelectedList(getSelected(), rows, getKeys()))
  }

  return { state, keyOf, checkableKeys, toggle, toggleAll }
}
```

> - `state` 是 `reactive(new Map())`：Map 的 `get(key)` 按 key 精确订阅。
> - `syncFromSelected` 以外部 `selected` 为准，外部清空 / 跨页返回 / 数据刷新都会同步。
> - 主键去重 / 差集复用 `@/hooks/useCheckAll` 的 `rowKeyOf` / `putSelectedList` / `deleteSelectedList`，不重复实现选择算法。
> - 树形表的子行不在 `items` 里：`getRows` 传入展开后的全部行，`getCheckableRows` 只给全选用的顶层行。

```ts
import type { ComputedRef, ShallowRef, VNode } from 'vue'
import type { DefaultRow } from 'element-plus/es/components/table/src/table/defaults'
import type { BaseCompTableProps, CellScope, HeaderScope, TableColumn, TableColumnFormat } from '../types'
import type { ColumnNodeSlots } from './CompTableColumn'
import type { FormatRaw } from '@/hooks/useFormatValue'
import type { CellColumnRef } from './CellRenderer'

import { computed, Fragment, shallowRef } from 'vue'
import { ElTableColumn } from 'element-plus'

import { useFormatValue } from '@/hooks/useFormatValue'
import { useRulesRequired } from '@/hooks/useRules'
import { RequiredHeader } from '@/hooks/useTable'

import CompPrice from '@/components/Price/index.vue'
import { CompTableCell } from './CellRenderer'
import { resolveColPath } from './columnPath'
import { CompTableColumn } from './CompTableColumn'

/** 列渲染需要的表格级默认值（全局对齐 / 最小宽度 / 必填规则） */
type ColumnDefaults<R extends DefaultRow> = Pick<BaseCompTableProps<any, R>, 'minWidth' | 'required' | 'align' | 'headerAlign' | 'isolateCellSlots'>

/** 按列格式化配置分派，保留 useFormatValue 各重载的参数约束 */
const formatCellValue = (raw: FormatRaw, format?: TableColumnFormat) => {
  if (!format) return useFormatValue(raw)
  if (format.type === 'enum') return useFormatValue(raw, 'enum', format.formatStr)
  if (format.type === 'dict') return useFormatValue(raw, 'dict', format.formatStr)
  return useFormatValue(raw, format.type, format.formatStr)
}

interface CreateDynamicColumnsOptions<R extends DefaultRow> {
  /** 已过滤的渲染列（分组 + 叶子） */
  dataColumns: ComputedRef<TableColumn<R>[]>
  /** 表格级 props（列未配置时取这里的默认值） */
  getTableProps: () => ColumnDefaults<R>
  /** 同一 prop 多个列声明的处理方式 */
  getColumnSlotMode: () => 'merge' | 'override'
}

/**
 * 稳定列 key 生成器（按列身份 = 层级 + 路径）：
 * - 列显隐只增删自身，其余列的 key 不变，避免 el-table-column 整体重挂载
 *   （重挂载会重新注册列、丢失列配置并触发多次 layout）
 * - 身份重复（未按约定传 key）时追加序号，保证同一级 vnode key 唯一
 */
const createColumnKey = () => {
  const occurrences = new Map<string, number>()
  return (identity: string) => {
    const times = occurrences.get(identity) ?? 0
    occurrences.set(identity, times + 1)
    return times ? `${identity}#${times}` : identity
  }
}

/** 展平默认插槽里的 Fragment（在 Vue 3 中，Fragment（片段） 是一个内置的虚拟包装概念，它允许组件模板拥有多个根节点，而无需像 Vue 2 那样必须包裹在一个单一的 <div> 里） / 数组，拿到 <CompTableColumn> 标记的 VNode */
const flattenVNodes = (children: unknown): VNode[] => {
  if (Array.isArray(children)) return children.flatMap(item => flattenVNodes(item))
  if (children && typeof children === 'object') {
    const vnode = children as VNode
    if (vnode.type === Fragment) return flattenVNodes(vnode.children)
    if ('type' in vnode) return [vnode]
  }
  return []
}

/**
 * 创建动态数据列函数式组件：
 * - 支持 children 递归渲染多级表头
 * - 单元格优先级：<CompTableColumn>#default > price > format
 * - 表头优先级：<CompTableColumn>#header > renderHeader=true > label
 *
 * 必须在 setup 同步执行期间调用（内部使用 useSlots）
 */
export const createDynamicColumns = <R extends Record<string, any>>({
  dataColumns,
  getTableProps,
  getColumnSlotMode
}: CreateDynamicColumnsOptions<R>) => {
  const slots = useSlots()
  const isRequiredByRules = useRulesRequired(() => getTableProps().required)

  /** <CompTableColumn> 没有提供任何插槽时的告警去重 */
  const warnedEmptyColumnNodes = new Set<string>()
  const warnEmptyColumnNode = (prop: string) => {
    if (!import.meta.env.DEV || warnedEmptyColumnNodes.has(prop)) return
    warnedEmptyColumnNodes.add(prop)
    console.warn(`[CompTable] 列 "${prop}" 的 <CompTableColumn> 没有 #header/#default 插槽，已忽略。`)
  }

  /** 合并同一 prop 的重复列声明：按声明顺序依次渲染（如内置操作列 + 消费方操作列） */
  const mergeSlot = <S>(prev?: (scope: S) => unknown, next?: (scope: S) => unknown) =>
    prev && next ? (scope: S) => [prev(scope), next(scope)] : next ?? prev

  /** 收集默认插槽里所有 <CompTableColumn prop="..."> 及其 #header/#default 插槽 */
  const collectColumnNodes = (): Map<string, ColumnNodeSlots<R>> => {
    const map = new Map<string, ColumnNodeSlots<R>>()
    flattenVNodes(slots.default?.()).forEach(vnode => {
      if (vnode.type !== CompTableColumn) return
      const prop = vnode.props?.prop
      if (prop == null) return

      const node: ColumnNodeSlots<R> = {}
      const raw = vnode.children
      if (raw && typeof raw === 'object' && !Array.isArray(raw)) {
        const rawSlots = raw as Record<string, unknown>
        node.header = rawSlots.header as ColumnNodeSlots<R>['header']
        node.default = rawSlots.default as ColumnNodeSlots<R>['default']
      } else if (Array.isArray(raw)) {
        // 直接写在 <CompTableColumn> 里的内容视为单元格插槽
        node.default = () => raw
      }

      if (!node.header && !node.default) warnEmptyColumnNode(String(prop))
      const propKey = String(prop)
      const existing = map.get(propKey)
      // 默认 override：后声明的列覆盖先声明的；merge：按声明顺序合并渲染
      map.set(
        propKey,
        existing && getColumnSlotMode() === 'merge'
          ? {
              header: mergeSlot(existing.header, node.header),
              default: mergeSlot(existing.default, node.default),
            }
          : node
      )
    })
    return map
  }

  interface ColumnRenderContext {
    columnNodes: Map<string, ColumnNodeSlots<R>>
    defaults: ColumnDefaults<R>
    keyOf: (identity: string) => string
    isolateCellSlots: boolean
  }

  interface LeafCellInput {
    col: TableColumn<R>
    scope: CellScope<R>
    cellSlot: ColumnNodeSlots<R>['default'] | undefined
    columnRef: CellColumnRef<R>
    indexRefs: WeakMap<object, ShallowRef<number>>
  }

  const renderLeafCell = ({ col, scope, cellSlot, columnRef, indexRefs }: LeafCellInput, ctx: ColumnRenderContext) => {
    // el-table-column 渲染时会以 $index=-1 探测一次 default 插槽来收集子列，此时不渲染单元格
    if (scope.$index < 0) return null
    if (cellSlot) {
      if (!ctx.isolateCellSlots) return cellSlot({ row: scope.row, column: scope.column, $index: scope.$index })
      columnRef.value = scope.column
      let indexRef = indexRefs.get(scope.row)
      if (!indexRef) {
        indexRef = shallowRef(scope.$index)
        indexRefs.set(scope.row, indexRef)
      } else if (indexRef.value !== scope.$index) {
        indexRef.value = scope.$index
      }
      return h(CompTableCell, {
        render: cellSlot,
        row: scope.row,
        columnRef,
        indexRef
      })
    }
    if (col.price) {
      return h(CompPrice, {
        price: scope.row[col.prop as keyof R],
        ...(col.priceConfig ?? {})
      })
    }
    return formatCellValue(scope.row[col.prop as keyof R] as FormatRaw, col.format)
  }

  const renderColumnHeader = (col: TableColumn<R>, scope: HeaderScope<R>, headerNode?: ColumnNodeSlots<R>['header']) => {
    if (headerNode) return headerNode({ column: scope.column, $index: scope.$index })
    if (col.renderHeader === true) {
      return h(RequiredHeader, {
        label: col.label,
        required: isRequiredByRules(String(col.prop))
      })
    }
  }

  const renderColumn = (col: TableColumn<R>, ctx: ColumnRenderContext, parentPath = '', depth = 0): VNode => {
    const path = resolveColPath(col, parentPath)
    const node = ctx.columnNodes.get(String(col.prop))
    const cellSlot = node?.default
    const headerNode = node?.header
    const hasChildren = !!col.children?.length && !cellSlot
    const columnRef: CellColumnRef<R> = { value: undefined }
    const indexRefs = new WeakMap<object, ShallowRef<number>>()

    const columnSlots: Record<string, (scope: any) => unknown> = {
      default: hasChildren
        ? () => col.children!.map(child => renderColumn(child, ctx, path, depth + 1))
        : (scope: CellScope<R>) => renderLeafCell({ col, scope, cellSlot, columnRef, indexRefs }, ctx)
    }
    if (headerNode || col.renderHeader === true) {
      columnSlots.header = (scope: HeaderScope<R>) => renderColumnHeader(col, scope, headerNode)
    }

    return h(
      ElTableColumn,
      {
        key: ctx.keyOf(`${depth}|${path}`),
        prop: hasChildren ? undefined : String(col.prop),
        label: col.label,
        width: col.width,
        minWidth: hasChildren ? col.minWidth : col.minWidth ?? ctx.defaults.minWidth,
        fixed: col.fixed,
        align: col.align ?? ctx.defaults.align,
        headerAlign: col.headerAlign ?? ctx.defaults.headerAlign ?? col.align ?? ctx.defaults.align,
        showOverflowTooltip: col.showOverflowTooltip,
        renderHeader: !headerNode && typeof col.renderHeader === 'function' ? col.renderHeader : undefined
      },
      columnSlots
    )
  }

  /**
   * 列 VNode 缓存：仅当 dataColumns（列结构/显隐）或表格级默认 props 变化时重建。
   * 行增删不改变 dataColumns，直接复用缓存引用。
   */
  const columnsRender = computed(() => {
    const defaults = getTableProps()
    const ctx: ColumnRenderContext = {
      columnNodes: collectColumnNodes(),
      defaults,
      keyOf: createColumnKey(),
      isolateCellSlots: defaults.isolateCellSlots !== false
    }
    return dataColumns.value.map(col => renderColumn(col, ctx))
  })

  return () => columnsRender.value
}
```

### ColumnVisibility/index.ts

```ts
import type { TableColumn } from '../CompBaseTable/types'

import { useLocalStorage } from '@vueuse/core'

import { resolveColPath } from '../CompBaseTable/columns/columnPath'

/** 全角空格用于显隐面板子列缩进（RightToolbar 不支持层级结构） */
const LEVEL_INDENT = '　'

/** 显隐面板条目 */
export interface ColumnVisibilityItem {
  key: string
  label: string
  visible: boolean
  level: number
  parentKey?: string
}

/**
 * 递归扁平化列结构为显隐列表：
 * - disabled 列跳过；分组子列全 disabled 时整组跳过
 * - 子列 label 加缩进前缀表达层级
 */
const flatten = <R>(cols: TableColumn<R>[], level = 0, parentKey?: string, parentPath = ''): ColumnVisibilityItem[] =>
  cols.flatMap(col => {
    if (col.disabled) return []
    const key = resolveColPath(col, parentPath)
    const label = level ? `${LEVEL_INDENT.repeat(level)}└ ${col.label}` : col.label
    if (col.children?.length) {
      const children = flatten(col.children, level + 1, key, key)
      return children.length ? [{ key, label, visible: col.visible !== false, level, parentKey }, ...children] : []
    }
    return [{ key, label, visible: col.visible !== false, level, parentKey }]
  })

/** 查找首个匹配的叶子列 */
const findLeaf = <R>(cols: TableColumn<R>[], fn: (c: TableColumn<R>) => boolean): TableColumn<R> | undefined => {
  for (const col of cols) {
    if (col.children?.length) {
      const hit = findLeaf(col.children, fn)
      if (hit) return hit
    } else if (fn(col)) {
      return col
    }
  }
}

interface Options<R extends Record<string, any>> {
  /** 列配置（getter，保持对 useCompTable 注入列 / 动态列结构的响应） */
  getColumns: () => TableColumn<R>[]
  /** 显隐持久化 localStorage key，空串不持久化 */
  getStorageKey: () => string
}

/**
 * 多级表头列显隐（父子级联）。支持运行时列结构变化（如切换预算任务），
 * 结构变化时重建条目并按 key 保留各列已有显隐状态
 */
export const useColumnVisibility = <R extends Record<string, any>>({ getColumns, getStorageKey }: Options<R>) => {
  /**
   * 显隐持久化状态（useLocalStorage，JSON 序列化与旧格式兼容）：
   * - 按列路径 key 存储（key 以 '/' 开头，永不纯数字）
   * - 旧格式为纯数字下标 key，读取时按下标兜底，persist 时迁移为新格式
   * - writeDefaults: false：无已存数据时不写入默认值
   */
  const savedState = useLocalStorage<Record<string, boolean>>(computed(() => getStorageKey()), {}, { writeDefaults: false })

  /** 存储中是否读到旧下标格式（挂载时需要迁移为新的路径格式） */
  let appliedLegacy = false

  /** 把存储的显隐状态应用到条目列表 */
  const applySaved = (list: ColumnVisibilityItem[]) => {
    if (!getStorageKey()) return
    const saved = savedState.value
    const keys = Object.keys(saved)
    if (!keys.length) return
    const legacy = keys.every(k => /^\d+$/.test(k))
    if (legacy) appliedLegacy = true
    list.forEach((item, idx) => {
      const value = legacy ? saved[idx] : saved[item.key]
      if (typeof value === 'boolean') item.visible = value
    })
  }

  /** 显隐条目列表（结构变化时原地 splice 重建，保留各列显隐状态） */
  const items = reactive(flatten(getColumns()))
  // 初始化即恢复显隐（异步列场景下此时为空转，列到达后由 rebuild 恢复）
  applySaved(items)

  /** key -> 自身可见状态（渲染过滤用） */
  const visMap = computed(() => new Map(items.map(i => [i.key, i.visible])))
  /** key -> 条目（级联时查父节点） */
  const itemMap = computed(() => new Map(items.map(i => [i.key, i])))
  /** 父 key -> 直接子条目列表（级联用） */
  const childrenMap = computed(() => {
    const map = new Map<string, ColumnVisibilityItem[]>()
    items.forEach(i => {
      if (!i.parentKey) return
      const list = map.get(i.parentKey) ?? []
      list.push(i)
      map.set(i.parentKey, list)
    })
    return map
  })

  /** 某分组下全部后代 */
  const descendants = (key: string): ColumnVisibilityItem[] => (childrenMap.value.get(key) ?? []).flatMap(kid => [kid, ...descendants(kid.key)])

  /** 某分组下全部叶子后代 */
  const leafDescendants = (key: string): ColumnVisibilityItem[] => descendants(key).filter(d => !childrenMap.value.get(d.key)?.length)

  /** 持久化（空列不写，避免覆盖异步列到达前的已存状态） */
  const persist = () => {
    if (!getStorageKey() || !items.length) return
    const state: Record<string, boolean> = {}
    items.forEach(i => (state[i.key] = i.visible))
    savedState.value = state
  }

  // ---------- 程序化写入守卫 ----------
  // ready=false：挂载时 RightToolbar 从 localStorage 恢复显隐，尚未开始接收用户操作
  // syncing    ：正在写子孙 / 祖先 visible 或重建条目，watcher 据此跳过级联
  let ready = false
  let syncing = false

  /** 执行程序化写入；watcher 为 flush: 'sync'，写入瞬间即被 syncing 拦下 */
  const silentWrite = (write: () => void) => {
    syncing = true
    try {
      write()
    } finally {
      syncing = false
    }
  }

  /** 对用户切换的列执行父子级联 */
  const cascade = (changed: ColumnVisibilityItem[]) => {
    silentWrite(() => {
      changed.forEach(item => {
        if (childrenMap.value.get(item.key)?.length) {
          // 分组：整组子孙跟随
          descendants(item.key).forEach(d => {
            d.visible = item.visible
          })
          return
        }
        // 叶子：自底向上，分组 visible = 子树是否存在可见叶子
        let pKey = item.parentKey
        while (pKey) {
          const parent = itemMap.value.get(pKey)
          if (parent) parent.visible = leafDescendants(parent.key).some(l => l.visible)
          pKey = parent?.parentKey
        }
      })
    })
    persist()
  }

  /**
   * 列结构变化时重建条目，按 key 保留显隐状态。
   * 用原地 splice 替换，保持 reactive 引用不变（RightToolbar 仍绑定同一数组）
   */
  const rebuild = () => {
    const prevVisible = new Map(items.map(i => [i.key, i.visible]))
    const next = flatten(getColumns())
    // 内存中无记录的新列（如异步列首次到达），从存储中按 key 恢复
    applySaved(next.filter(i => !prevVisible.has(i.key)))
    silentWrite(() => {
      items.splice(0, items.length, ...next.map(i => ({ ...i, visible: prevVisible.get(i.key) ?? i.visible })))
    })
    // 结构变化后回写存储，避免已删除列 / 旧下标格式残留
    persist()
  }
  // 深度监听列配置：结构相同则不触发，结构变化才重建（Vue 内部做深度比较）
  watch(getColumns, rebuild, { deep: true })

  /**
   * 挂载后：按叶子状态归并分组显隐（修复历史存储中"父隐藏/子显示"的不一致），
   * 之后才开始接收用户操作。仅在状态确实变化或需要迁移旧格式时回写存储，
   * 避免每次挂载都产生一次无意义的 localStorage 写入
   */
  onMounted(() =>
    nextTick(() => {
      let changed = false
      silentWrite(() => {
        items.forEach(i => {
          if (!childrenMap.value.get(i.key)?.length) return
          const visible = leafDescendants(i.key).some(l => l.visible)
          if (visible === i.visible) return
          i.visible = visible
          changed = true
        })
      })
      if (changed || appliedLegacy) persist()
      ready = true
    })
  )

  /**
   * 监听各列 visible 变化：仅处理用户主动切换（级联 / 恢复 / 重建均已同步置位 syncing）。
   * flush: 'sync' 让 silentWrite 能拦截本次写入引发的回调，无需跨 tick 复位标记
   */
  watch(
    () => items.map(i => [i.key, i.visible] as const),
    (_curr, prev) => {
      if (!ready || syncing) return
      const prevVisible = new Map(prev)
      const changed = items.filter(i => prevVisible.get(i.key) !== i.visible)
      if (changed.length) cascade(changed)
    },
    { flush: 'sync' }
  )

  // ---------- 渲染过滤 ----------
  /**
   * 递归过滤多级表头：
   * - 叶子生效可见 = 自身可见 && 所有祖先可见（父隐藏级联隐藏全部子列）
   * - disabled / prop='index' 叶子剔除（序号列单独静态渲染）
   * - 分组无生效子列时整组剔除
   */
  const filterTree = (cols: TableColumn<R>[], parent = '', parentVis = true): TableColumn<R>[] =>
    cols.flatMap(col => {
      if (col.disabled) return []
      const key = resolveColPath(col, parent)
      const own = visMap.value.get(key) ?? col.visible !== false
      const eff = parentVis && own
      if (col.children?.length) {
        const ch = filterTree(col.children, key, eff)
        return ch.length ? [{ ...col, children: ch }] : []
      }
      if (col.prop === 'index' || col.prop === 'expand') return []
      return eff ? [col] : []
    })

  const dataColumns = computed(() => filterTree(getColumns()))
  const indexColumnConfig = computed(() => findLeaf(getColumns(), c => c.prop === 'index'))
  const expandColumnConfig = computed(() => findLeaf(getColumns(), c => c.prop === 'expand'))

  return { columnVisibility: items, dataColumns, indexColumnConfig, expandColumnConfig }
}
```

```ts
import type { ComputedRef, MaybeRefOrGetter } from 'vue'
import type { CompTableColumnComponent } from '../columns/CompTableColumn'
import type { TableColumn } from '../types'

import { computed, getCurrentInstance, inject, provide, toValue } from 'vue'

import { compTableColumnsKey, CompTableColumn } from '../columns/CompTableColumn'
import { createBoundCompBaseTable } from './boundCompTable'

/** 每个组件实例自己的注入表，保证同一 setup 多次调用不会互相覆盖 */
const localColumnsMaps = new WeakMap<object, Map<string, ComputedRef<TableColumn<any>[]>>>()

/**
 * 取当前组件的注入表
 * - 首次调用才继承父级注入（inject 只读父级 provides），保证子组件里的 CompTable 仍能拿到父级列
 * - 后续调用直接复用，避免被空表覆盖
 */
const resolveColumnsMap = (instance: object) => {
  const cached = localColumnsMaps.get(instance)
  if (cached) return cached

  const columnsMap = new Map(inject(compTableColumnsKey, null) ?? [])
  provide(compTableColumnsKey, columnsMap)
  localColumnsMaps.set(instance, columnsMap)
  return columnsMap
}

/** 注册列，返回带行类型插槽推导的 CompTableColumn 与绑定 tableKey 的 CompBaseTable */
export const useCompTable = <R extends Record<string, any>>(
  columns: MaybeRefOrGetter<TableColumn<R>[]>,
  key = 'default',
) => {
  const instance = getCurrentInstance()
  if (!instance) throw new Error('[CompTable] useCompTable() 必须在 setup 中调用')

  resolveColumnsMap(instance).set(key, computed(() => toValue(columns)))

  return {
    CompTableColumn: CompTableColumn as unknown as CompTableColumnComponent<R>,
    CompBaseTable: createBoundCompBaseTable(key),
  }
}
```

### CompBaseTable/composables/useTableColumns.ts

```ts
import type { BaseCompTableProps, TableColumn } from '../types'

import { computed, inject, watchEffect } from 'vue'

import { compTableColumnsKey } from '../columns/CompTableColumn'

const filterRenderable = <R>(cols: TableColumn<R>[]): TableColumn<R>[] =>
  cols.flatMap(col => {
    if (col.disabled) return []
    if (col.children?.length) {
      const children = filterRenderable(col.children)
      return children.length ? [{ ...col, children }] : []
    }
    return col.prop === 'index' || col.prop === 'expand' ? [] : [col]
  })

const findLeaf = <R>(cols: TableColumn<R>[], prop: string): TableColumn<R> | undefined => {
  for (const col of cols) {
    if (col.children?.length) {
      const hit = findLeaf(col.children, prop)
      if (hit) return hit
    } else if (col.prop === prop) {
      return col
    }
  }
}

export const useTableColumns = <R extends Record<string, any>>(props: BaseCompTableProps<any, R>) => {
  const tableKey = computed(() => props.tableKey ?? 'default')
  const columnsMap = inject(compTableColumnsKey, null)
  const injectedColumns = computed<TableColumn<R>[]>(
    () => (columnsMap?.get(tableKey.value)?.value ?? []) as TableColumn<R>[]
  )
  const sourceColumns = computed<TableColumn<R>[]>(() => props.columns ?? injectedColumns.value)

  const warned = new Set<string>()
  watchEffect(() => {
    if (!import.meta.env.DEV || props.columns || !columnsMap || columnsMap.has(tableKey.value) || warned.has(tableKey.value)) return
    warned.add(tableKey.value)
    console.warn(
      `[CompTable] table-key "${tableKey.value}" 未在 useCompTable 中注册，已注册：${[...columnsMap.keys()].join(', ') || '(无)'}`
    )
  })

  return {
    sourceColumns,
    dataColumns: computed(() => filterRenderable(sourceColumns.value)),
    indexColumnConfig: computed(() => props.indexColumnConfig ?? findLeaf(sourceColumns.value, 'index')),
    expandColumnConfig: computed(() => props.expandColumnConfig ?? findLeaf(sourceColumns.value, 'expand'))
  }
}
```

```ts
import type { Ref } from 'vue'

import { useTableHeight } from '@/hooks/useTable'

export const useCompTableHeight = <T extends Record<string, any>, R extends Record<string, any>>(
  targetRef: Ref<object | null | undefined>,
  props: BaseCompTableProps<T, R>

  const resolvedHeight = computed<ID | undefined>(() => {
    if (props.height != null) return props.height
    return props.heightMode === 'fixed' ? tableHeight.value : undefined
  })

    if (props.height != null || props.heightMode !== 'max') return undefined
    return props.maxHeight ?? tableHeight.value
  })

  const schedule = () => {
    cancelAnimationFrame(raf)
    raf = requestAnimationFrame(refresh)
  }

  // 作用域销毁时同样取消待执行的 rAF，避免销毁后回调
  onScopeDispose(() => cancelAnimationFrame(raf))

  return { resolvedHeight, resolvedMaxHeight, refresh }
}
```

### utils/selectionKey.ts

```ts
/**
 * 行选择 / 跨页选择的纯计算工具。
 * 不依赖 Vue、Element Plus 或若依 hooks，CompTable 核心与 useCheckAll 共用。
 */

/** 跨页选择行需要的最小字段 */
export type SelectableRow = { checked?: boolean; disabled?: boolean }

/** 拆分复合主键：'id' / 'id-type' → ['id', 'type'] */
export const splitKeys = (keys: string) => keys.split('-').filter(Boolean)

/**
 * 行主键：按主键字段顺序序列化，保留类型（1 与 '1' 不相等）。
 * 用 JSON 而不是字符串拼接，字段值里含分隔符时也不会产生歧义。
 */
export const rowKeyOf = (row: object, fields: string[]) => JSON.stringify(fields.map(field => Reflect.get(row, field)))

/** 跨页选择-初始数据是否选中 */
export function isChecked<T extends object>(arr: T[], keys: string, item: T) {
  const fields = splitKeys(keys)
  const itemKey = rowKeyOf(item, fields)
  return arr.some(row => rowKeyOf(row, fields) === itemKey)
}

/** 跨页选择-获取指定字段值的数据 */
export function getArrayBySelectedList<T extends object>(arr: T[], keys: string, value: (ID | boolean)[], getKey: string): string[] {
  const fields = splitKeys(keys)
  const array: string[] = []
  arr.forEach(item => {
    if (fields.every(field => value.includes(Reflect.get(item, field) as ID | boolean))) array.push(Reflect.get(item, getKey) as string)
  })
  return array
}

/** 跨页选择-插入数据（按主键去重，返回新数组，不修改入参） */
export function putSelectedList<T extends object>(arr: T[], putArr: T[], keys: string): T[] {
  const fields = splitKeys(keys)
  const merged = arr.slice()
  const existing = new Set(merged.map(row => rowKeyOf(row, fields)))
  putArr.forEach(row => {
    const key = rowKeyOf(row, fields)
    if (existing.has(key)) return
    existing.add(key)
    merged.push(row)
  })
  return merged
}

/** 跨页选择-删除数据（按主键过滤，返回新数组，不修改入参） */
export function deleteSelectedList<T extends object>(arr: T[], delArr: T[], keys: string): T[] {
  const fields = splitKeys(keys)
  const removed = new Set(delArr.map(row => rowKeyOf(row, fields)))
  return arr.filter(row => !removed.has(rowKeyOf(row, fields)))
}
```

>     { key:'/custom-budgetInfo/expFunctionId', ... },
>     { key:'/custom-budgetInfo/deptSubjectId', ... },
>   ]
>   ```
>
> * leafDescendants('/custom-budgetInfo')某分组下所有 叶子 后代（没有子列的）只含叶子后代,过滤掉有子列的中间分组
>
>
>
> 级联行为示例:
>
> 场景 A：用户取消勾选分组「所属项目预算信息」
>
> ```ts
> cascade([{ key:'/custom-budgetInfo', visible:false }])
>   → 它是分组（childrenMap 里有它）
>   → descendants 全部设为 false
>   → subItemName / expFunctionId / deptSubjectId 都变 false
>   → RightToolbar 面板里这 3 个子项也跟着取消勾选
> ```
>
> 场景 B：用户取消勾选叶子「组目名称」
>
> ```
> cascade([{ key:'/custom-budgetInfo/subItemName', visible:false }])
>   → 它是叶子
>   → 自底向上：找父 /custom-budgetInfo
>     → leafDescendants('/custom-budgetInfo') = [subItemName, expFunctionId, deptSubjectId]
>     → 其中 expFunctionId / deptSubjectId 还是 true
>     → 父 visible = some(叶子可见) = true（分组仍显示）
> ```
>
> 只有当这 3 个叶子 全部 取消，分组才会自动取消勾选。
>
> **rebuild = 用新列结构重建 items，但把旧列的显隐记忆搬过去，同时保证引用不变、不触发误级联。**

## 编辑态与行增删性能

### 1. 单元格隔离（默认开启）

`<CompTableColumn #default>` 的插槽原本由 el-table 表体执行，插槽里 `v-model="row.field"` 会让表体的 render effect 读到行字段；改一个输入框就会重跑所有单元格插槽。

`CompBaseTable/columns/CellRenderer.ts` 把插槽放进 `CompTableCell` 子组件：
- 表体只创建组件 vnode，不执行插槽、不读行字段；
- 行字段读取发生在该单元格组件自己的 render 里，编辑时只重渲染当前单元格；
- `columnRef` 用普通对象传列配置，避免 el-table 每次渲染的新 column 对象把全部子组件标记为 props 变化。

开关：`:isolate-cell-slots="false"` 可关闭（默认 true）。

### 2. `$index` 按需订阅

`$index` 通过 scope getter 暴露，底层是每个单元格的 `indexRef`：

```ts
return props.render({
  row: props.row,
  column,
  get $index() {
    return props.indexRef.value
  }
})
```

- 插槽解构 `{ row }`：不读 getter，`$index` 变化不会触发重渲染；
- 插槽解构 `{ row, $index }`（包括 `items.${$index}.amount` 校验路径）：读取 getter，序号变化时该单元格自动更新；
- 不需要 `cell-index` 之类的开关，也没有“关闭后拿不到 `$index`”的兼容问题。

### 3. 实测（20 行 × 10 列编辑态，dev + headless Chrome）

| 场景 | 隔离 + 插槽不用 `$index` | 隔离 + 插槽使用 `$index` | 关闭隔离 |
| --- | --- | --- | --- |
| 编辑一个单元格 · 插槽执行次数 | **1** | **1** | 200 |
| 新增一行 · 插槽执行次数 | **10** | **10** | 210 |
| 删除首行 · 插槽执行次数 | **0** | 190（其余行索引前移，必须更新） | 200 |
| 单次操作 JS | 7–11 ms | 8–14 ms | 8–11 ms |

> 数组 `splice/push` 仍会让 el-table 表体 patch；上表是“单元格插槽执行次数”。使用 `$index` 的校验表格在删除中间行时，索引前移导致的重渲染是校验路径本身要求的，无法省掉。
> 简单 `el-input` 时 JS 差异不大，编辑器越重（form-item / select / 日期组件），减少 200 次插槽执行的收益越明显。

### 4. 非分页大量行

el-table 本身一次性渲染所有行，CompTable 没有引入虚拟滚动（会改变表格结构 / 固定列 / 树形 / 合计等行为）。当前优化只能降低「编辑、增删行」的重渲染量，**不能降低首次挂载的单元格数量**。几千行仍建议分页，或改用虚拟表格方案。

## 多选方案对比

同一份 `CompTable` 提供两套多选实现，页面 API 完全一致（`v-model:selected`、`:keys`、`@update:selected`）。
两套目录的 `index.vue`、`Toolbar/`、`ColumnVisibility/` **完全一致**，差异只在 `CompBaseTable/selection/`：`SelectionCheckbox.ts` + `useCompTableSelection.ts`（P0-1）与 `useNativeSelection.ts`（P0-2），差分源码见「[EP 原生多选 P0-2](#ep-原生多选-p0-2)」。

| 目录 | 方案 | 勾选态存放 | 适用场景 |
| --- | --- | --- | --- |
| `CompTable/` | **P0-1 自定义**（项目采用） | `CompBaseTable` 内部 `reactive Map<rowKey, boolean>` | 平铺表、树形表、跨页选择 |
| `CompTable-EP原生多选/` | P0-2 EP 原生 `type="selection"` | el-table 内部 `selection` | 平铺表；代码更少 |

### 为什么要改

el-table 对 `data` 开了 `deep: true` 的 watch：

```js
// node_modules/element-plus/es/components/table/src/table/style-helper.mjs
watch(() => props.data, (data) => table.store.commit('setData', data), { immediate: true, deep: true })
```

旧实现用 `<el-checkbox v-model="row.checked">`，勾选一次就改行对象 → `setData` → 整表重渲染。
200 行 × 46 列实测：**单次勾选 JS 约 425 ms**；20 行分页页面也要 40–47 ms。

### 实测数据

环境：headless Chrome、Element Plus 2.13.1、dev 构建、200 行 × 46 列（多级表头 + 4 种格式化 + 金额 + 插槽列）。仅作相对比较。

| 场景 | 旧 `row.checked` | P0-1 自定义 | P0-2 原生 selection |
| --- | --- | --- | --- |
| 单行勾选 · JS | **425 ms** | **1.5–1.9 ms** | 12–13 ms |
| 单行勾选 · 总耗时 | 481 ms | 33 ms | 50 ms |
| 表头全选 · JS | 426 ms | 16–18 ms | 0.1 ms |
| 表头全选 · 总耗时 | 455 ms | 50–68 ms | 65–115 ms |
| 取消一行（200 已选）· JS | 417–492 ms | 1.5–2.1 ms | 12–18 ms |
| 换页后返回、恢复 200 行勾选 | — | 672–709 ms | 773–1440 ms |
| 20 行单行勾选 · JS | 40–47 ms | 1.3–1.4 ms | 3.6–8.2 ms |
| 挂载 200 行 | 1.14–1.18 s | 1.22–1.41 s | 1.33–1.53 s |

> 总耗时含 `nextTick` 后等 2 帧 rAF（约 31 ms 基线），比较性能时看 JS 列。
> 分层重构后用 6 列 × 200 行复测：P0-1 单行 1.4–1.7 ms、P0-2 8.9–10 ms，结论不变；同一 6 列表格挂载 `CompBaseTable` 173–194 ms、拼装层 292–332 ms（差值是 TableToolbar + 显隐）。
>
> **结论：两者都比旧实现快一个数量级；综合更推荐 P0-1。**
> P0-1 单行、全选、恢复都更快且稳定；P0-2 批量全选的 JS 极少（EP 内部批量改 selection），但端到端还要等 200 个勾选态刷新，反而更慢；恢复 200 行勾选时逐行 `toggleRowSelection` 也明显更贵。

### 树形表差异（本项目有树形多选页面）

| 行为 | P0-1 | P0-2 |
| --- | --- | --- |
| 勾选子行 | ✅ | ✅ |
| 表头全选范围 | 仅顶层行（与改造前一致） | 会连子行一起选中 |
| 换页 / 刷新后恢复子行勾选 | ✅ | ❌（`toggleRowSelection` 对不在 `data` 里的子行无效） |
| 写 `row.checked` | 不写 | 不写 |

> 所以项目里 `jobTitlesInfo` / `jobTitlesLevel` 这类树形多选页面必须用 P0-1；P0-2 只作平铺表参考实现。

### 迁移注意

1. **页面不再依赖 `row.checked`**：批量操作用 `selected`（`jobTitlesInfo` / `jobTitlesLevel` 已改）。
2. 页面里的 `isCheckedItem(rows)` 可以保留（无副作用），但 CompTable 已以 `selected` 为准，不再需要它来恢复勾选。
3. `keys` 为空时，勾选态用 `WeakMap` 按行对象生成 key，各行独立；**跨页选择必须显式传 `keys`**。
4. `row-key` 回退从字符串改成了函数，支持 `keys="id-type"` 复合主键（EP 字符串 row-key 只支持 `.` 路径，不认 `-`）。
5. 纯选择计算在 `@/utils/selectionKey.ts`；`useCheckAll` 只是转出（保持 `@/hooks/useCheckAll` 引用兼容），Select 等组件继续使用。
6. 外部清空 `selected` 现在会同步清空行内勾选；全选态由共享 Map 汇总，不再依赖行上的 `checked`。

### 如何切换成 P0-2

1. 用 `CompTable-EP原生多选/CompBaseTable/` 覆盖 `CompTable/CompBaseTable/`：保留 `index.vue`、`types.ts`、`columns/`、`composables/`；把 `selection/` 换成 `useNativeSelection.ts`，并改 `CompBaseTable/index.vue` 的选择列。
2. `CompBaseTable/index.vue` 已改成 `type="selection"` + `@selection-change`；需要保证 `keys` 或 `rowKey` 有值，否则 `toggleRowSelection` 恢复勾选会失效。
3. 树形表不要切换（见上表）。

### P0-2 selection/useNativeSelection.ts

```ts
import { computed, nextTick, watch } from 'vue'

import { putSelectedList, rowKeyOf, splitKeys } from '@/utils/selectionKey'

export interface NativeSelectionTable<R> {
  toggleRowSelection: (row: R, selected?: boolean) => void
}

interface Options<R extends Record<string, any>> {
  getKeys: () => string
  getSelected: () => R[]
  getRows: () => R[]
  getTable: () => NativeSelectionTable<R> | null | undefined
  onSelectedChange: (rows: R[]) => void
}

export const useNativeSelection = <R extends Record<string, any>>({
  getKeys,
  getSelected,
  getRows,
  getTable,
  onSelectedChange
}: Options<R>) => {
  const fields = computed(() => splitKeys(getKeys()))
  const fallbackKeys = new WeakMap<object, string>()
  let fallbackSeed = 0

  const keyOf = (row: R) => {
    if (fields.value.length) return rowKeyOf(row, fields.value)
    let key = fallbackKeys.get(row)
    if (!key) {
      key = `row-${++fallbackSeed}`
      fallbackKeys.set(row, key)
    }
    return key
  }

  let syncing = false
  let lastEmitted: R[] | null = null
  let lastRows: R[] | null = null

  const sameSelection = (a: R[], b: R[]) => {
    if (a.length !== b.length) return false
    const bKeys = new Set(b.map(row => keyOf(row)))
    return a.every(row => bKeys.has(keyOf(row)))
  }

  const handleSelectionChange = (rowsSelected: R[]) => {
    if (syncing) return
    const rows = getRows()
    const pageKeys = new Set(rows.map(row => keyOf(row)))
    const kept = getSelected().filter(row => !pageKeys.has(keyOf(row)))
    const next = putSelectedList(kept, rowsSelected, getKeys())
    if (sameSelection(next, getSelected())) return
    lastEmitted = next
    onSelectedChange(next)
  }

  const syncTableSelection = async () => {
    const rows = getRows()
    const selected = getSelected()
    const rowsChanged = rows !== lastRows
    lastRows = rows
    if (!rowsChanged && lastEmitted && sameSelection(selected, lastEmitted)) return
    syncing = true
    try {
      await nextTick()
      const table = getTable()
      if (!table) return
      const selectedKeys = new Set(selected.map(row => keyOf(row)))
      rows.forEach(row => {
        const should = selectedKeys.has(keyOf(row))
        if (rowsChanged && !should) return
        table.toggleRowSelection(row, should)
      })
    } finally {
      syncing = false
    }
  }

  watch([() => getRows(), () => getSelected()], syncTableSelection, { immediate: true })

  return { keyOf, handleSelectionChange }
}
```

> P0-2 使用 el-table 内部 selection，不写 `row.checked`；跨页时合并当前页之外已选行。
> 树形子行恢复依赖 `toggleRowSelection`，对不在 `data` 里的子行无效，因此树形多选页面继续用 P0-1。

> `const { CompBaseTable: BaseTableB } = useCompTable(columnsB, 'b')`。

> 如果只想用 EP 层（不要工具栏 / 显隐），可以解构 hook 返回的 `CompTable`：
> `const { CompTable: BaseTableB } = useCompTable(columnsB, 'b')`。

> `const isRequiredByRules = useRulesRequired(() => props.required)`
>
> 高阶函数（闭包 / 柯里化）
>
> ```ts
> // 第 1 步：传入 rules，返回一个函数（此时还没判定任何东西）
> const isRequiredByRules = useRulesRequired(() => props.required)
> //    ↑ 此时 isRequiredByRules 的类型是 (key: string) => boolean，不是 boolean
>
> // 第 2 步：调用这个返回的函数，传入 key，才真正执行判定
> isRequiredByRules('pkAccountId')  // → boolean
> ```
>
> 关键点：
>
> - useRulesRequired外层函数 接收`rules` ， 内层函数 接收`key` 。两者参数不同，所以不冲突、不报错。
> - `rules` 被内层函数通过 闭包 捕获，不需要第二次传进来。
> - TypeScript 也完全对得上：`useRulesRequired` 的类型是`(rules) => (key: string) => boolean` ，`isRequiredByRules` 的推断结果就是`(key: string) => boolean` ，所以调用时传`key` 合法。
>
> 因为「规则集合」在一张表里是 共享的 （所有列都用同一个`props.required` ），而「key」是 每列独有的 （`col.prop` 各不相同）。柯里化把这两者分离：
>
> 等价于把`rules` 提前「绑定」好，得到一个只差`key` 的函数，从而可以在`v-for` 中对所有列复用同一个判定逻辑。
>
> 如果不想用柯里化，也可以写成一次性收两个参数的形式
>
> 只是那样每次调用都要重复传`props.required` ，柯里化更省一点

## 附：树的遍历（DFS / BFS）

一句话： DFS 就是递归时先深入子节点、再处理兄弟节点的遍历方式 。

### DFS（深度优先搜索）

核心思想： 一条路走到黑，走不通再回头 。遇到一个节点，先往它的子节点钻，直到没有子节点了，再回退到上一层试别的分支。

遍历顺序： A → B → B1 → B2 → C → C1

### BFS（广度优先搜索）

A → B → C → B1 → B2 → C1

### 树的术语

```
              A              ← 有子节点（B、C），不是叶子
             / \
            B   C            ← B 有子节点（D、E），不是叶子；C 没有子节点 → 叶子
           / \
          D   E              ← D、E 没有子节点 → 叶子
```

| 术语                | 含义                        | 例子                         |
| ------------------- | --------------------------- | ---------------------------- |
| 子节点（children）  | 直接下一层                  | A 的子 = B、C；B 的子 = D、E |
| 后代（descendants） | 所有下层层级（子 + 孙 + …） | A 的后代 = B、C、D、E        |
| 叶子（leaf）        | 没有子节点 的节点           | C、D、E（它们下面没有了）    |
| 中间节点 / 分组     | 有子节点的节点              | A、B                         |
