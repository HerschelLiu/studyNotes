## 阅读路径

- **刚接手 Vue3 + Element Plus 项目**：`组件库/` → `hooks/` → `若依/` → `工程化/个人使用创建新项目准备.md`
- **补 JS 基础 / 面试**：`基础/` → `基础/前端面试题.md`
- **写小程序**：`小程序/微信小程序/`（构建、路由、分包、图片处理）→ `hooks/只用于微信小程序/`
- **组件要按代码维护**：`组件库/element-plus/` 下每个组件目录都带源码，改代码后同步文档源码区

## 维护提示

- 组件文档（`组件库/`、`hooks/`）的「源码」章节应与同目录 `.vue` / `.ts` 文件逐字一致，改代码必须同步文档。
- 新增 hook 文档放 `hooks/` 下对应平台子目录，并在 `hooks/README.md` 登记。
