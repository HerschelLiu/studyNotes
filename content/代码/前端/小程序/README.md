- **从零搭原生小程序**：`微信小程序/使用gulp从0构建原生小程序.md` → `gulp+typescript.md` → `小程序router.md`
- **uni-app 项目**：`DCloud/uniapp-ts.md` → `DCloud/组件/` → `DCloud/发行H5如何配置进php.md`
- **apicloud 老项目维护**：`apicloud/APIcloud笔记.md` → 常用模块 → 弹窗类组件

## 维护约定

- 与框架无关的 hooks/工具在 `前端/hooks/`（`只用于微信小程序`、`uniapp` 两个子目录），这里只放平台/框架本身的用法。
- 带源码的示例（`自定义音频播放器/`、`小程序行为/`）文档中的代码块应与源码文件保持一致。
