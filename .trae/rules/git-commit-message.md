# Git 提交信息规范

提交信息必须使用以下格式：`<type>: [<模块名称>]<描述>`

## 类型（type）

| 类型     | 说明                                              |
| -------- | ------------------------------------------------- |
| feat     | 新功能（feature）                                 |
| fix      | 修补 bug                                          |
| docs     | 文档（文档更新、提审添加更新日志）                |
| style    | 格式（不影响代码运行的变动）                      |
| refactor | 重构（即不是新增功能，也不是修改 bug 的代码变动） |
| test     | 增加测试                                          |
| chore    | 构建过程或辅助工具的变动                          |

## 模块名称（scope）

- 使用方括号 `[]` 包裹
- 模块名称应简洁明确，例如 `[会计平台]`、`[总预算]`、`[hooks]`、`[构建]`
- 跨模块时用 `/` 分隔，例如 `[会计平台/总预算]`
- 提审类日志统一使用 `[提审]`

## 描述（subject）

- 简明扼要说明本次提交内容
- 不以句号结尾

## 示例

```
feat: [会计平台-事件明细查询-供应链]新增静态页面
fix: [hooks]修复表格高度计算错误
docs: [提审]添加更新日志
style: [组件]格式化代码缩进
refactor: [会计平台/总预算]新增 CompTable 通用表格组件并改造所有 table.vue
test: [工具函数]添加 useTableHeight 单元测试
chore: [构建]更新 vite 配置
```
