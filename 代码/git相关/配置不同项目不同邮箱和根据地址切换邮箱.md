### 仅对当前仓库单独设置

`--local` 配置只对当前仓库生效,优先级高于 `--global`,不会影响 gitee/公司仓库:

```bash
cd /Users/herschel/Documents/study/studyNotes
git config --local user.email "你的noreply邮箱@users.noreply.github.com"
```



### 按 remote URL 自动切换

git 2.36+ 支持 `hasconfig:remote.*.url:` 条件,可以根据远程仓库地址自动应用不同配置。所有 GitHub 仓库自动用 noreply 邮箱,其他仓库继续用全局邮箱。



在 `~/.gitconfig` 末尾追加以下内容

```ini
[includeIf "hasconfig:remote.*.url:git@github.com:*/"]
    path = ~/.gitconfig-github

[includeIf "hasconfig:remote.*.url:https://github.com/"]
    path = ~/.gitconfig-github
```



然后新建文件 `~/.gitconfig-github`:

```ini
[user]
    email = 你的ID+HerschelLiu@users.noreply.github.com
```
