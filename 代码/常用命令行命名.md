### 通用
```bash
# 在当前目录创建文件(可创建多个，空格分割)
touch .env

# 在指定目录创建
touch ~/Documents/.secret.txt

# 创建并写入内容
echo "API_KEY=12345" > .env

# 追加内容
echo "DEBUG=true" >> .env

# 创建空文件
echo "" > .hidden

# 从终端输入内容创建（按 Ctrl+D 结束）
cat > .config
# 输入内容后按 Ctrl+D

# 从另一个文件复制内容
cat existing.txt > .newhidden
```



### mac

```bash
# 打开当前目录
open .

# 打开指定文件夹
open /Users/你的用户名/Documents

# 打开当前用户的家目录
open ~

# 打开下载文件夹
open ~/Downloads

# 打开访达并选中指定文件
open -R /path/to/your/file.txt

# 快速查看当前文件的父目录
# 如果你知道文件路径
open -R $(pwd)/filename.txt
# 或者先 cd 到目录，再打开
cd /some/path
open -R file.txt
```

| 操作系统    | 等效命令   | 作用说明                                                  |
| :---------- | :--------- | :-------------------------------------------------------- |
| **macOS**   | `open`     | 用默认程序打开文件、文件夹或 URL                          |
| **Linux**   | `xdg-open` | 功能与 `open` 基本一致，是 Linux 桌面环境下的通用打开命令 |
| **Windows** | `start`    | 在命令提示符(cmd)或 PowerShell 中使用，功能类似           |
