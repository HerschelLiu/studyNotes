# 使用说明

> 苹方（PingFang）字体文件与引入方式，用于统一移动端/桌面端中文字体表现。

## 文件

| 文件 | 说明 |
| --- | --- |
| `fonts/PINGFANG_REGULAR.TTF` | 常规体（PingFang SC Regular） |
| `fonts/PINGFANG_MEDIUM.TTF` | 中等粗细（PingFang SC Medium） |
| `fonts/PINGFANG_BOLD.TTF` | 粗体（PingFang SC Bold） |
| `font.css` | `@font-face` 声明 + 全局字体覆盖 |

## 用法

1. 把 `fonts/` 与 `font.css` 一起放进项目静态资源目录（`font.css` 里用的是相对路径 `fonts/xxx.TTF`，目录结构不能拆开）。
2. 在入口文件引入：

```ts
import '@/assets/font/font.css'
```

3. `font.css` 默认只声明了 `pingfangMedium`，把 `body/button/input/select/textarea` 全部覆盖成苹方。需要其它字重时按同样格式补 `@font-face`：

```css
@font-face {
  font-family: "pingfangRegular";
  src: url("fonts/PINGFANG_REGULAR.TTF");
}
```

## 说明

- 苹方是 macOS / iOS 系统字体，**Windows、Android 不自带**，所以 Web 项目必须整包引入，否则会回退到 `arial, sans-serif`。
- 参考爱奇艺、腾讯视频的字族写法：`PingFangSC-Regular, 'Helvetica Neue', arial, sans-serif`。
- 中文站整包引入 TTF 体积较大（三个字重合计通常十几 MB），上线前建议裁剪子集或改用 WOFF2。
