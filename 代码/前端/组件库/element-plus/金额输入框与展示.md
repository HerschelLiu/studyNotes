# 金额输入框与展示

> 两个配套组件：
>
> - **`Price`（展示）**：后端存「分」，展示成「元」，支持符号 / 单位 / 小数 / 千分位 / 负数。
> - **`InputPrice`（输入）**：显示元、`v-model` 存分，输入后自动换算并夹在 `min`~`max` 之间。

## Price（展示）

### Props

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `price` | `string \| number \| null` | `''` | 价格；空字符串 / `null` / `undefined` 视为空值，展示 `--` |
| `showSign` | `boolean` | `true` | 是否显示 `￥` 符号 |
| `type` | `string` | `''` | 前置符号（如「原价」「现价」标签） |
| `double` | `boolean` | `false` | 是否展示小数部分 |
| `unit` | `string` | `''` | 后置单位（如 `/月`） |
| `priceUnit` | `string` | `'fen'` | 价格单位：`'fen'` 时 `price / 100`，否则按元直接展示 |
| `signStyle` | `string` | `''` | 符号的行内样式 |
| `isThousand` | `boolean` | `false` | 是否千分位（走 `ToThousandFilter`） |

### 展示规则

- 空值（`''` / `null` / `undefined`）→ `--`，不显示符号。
- `priceUnit = 'fen'` → 先除以 100 再格式化；负数时 `-` 前置到 `￥` 前面（如 `-￥5.00`）。
- `double = false` 时不渲染小数部分；`isThousand = true` 时整数部分加千分位。

### 源码

```vue
<template>
  <span class="price">
    <!--type start-->
    <span
      v-if="type"
      class="type">
      {{ type }}
    </span>
    <!--type end-->

    <!--sign start（负数时符号前置，如 "-￥5.00"）-->
    <span
      v-if="pix < 0 && showSign"
      class="sign">
      -
    </span>
    <span
      v-if="showSign && !isNaN(pix)"
      class="sign"
      :style="signStyle">
      ￥
    </span>
    <!--sign end-->

    <!--number start-->
    <span class="number">
      <span>{{ int }}</span>
      <span
        v-if="decimal"
        class="decimal">
        {{ decimal }}
      </span>
    </span>
    <span
      v-if="unit"
      class="unit">
      {{ unit }}
    </span>
    <!--number end-->
  </span>
</template>

<script lang="ts">
  export default {
    name: 'Price'
  }
</script>

<script lang="ts" setup>
  import { ToThousandFilter } from '@/filters'

  export interface Props {
    /** 是否显示符号 */
    showSign?: boolean
    /** 价格（null/undefined/空字符串 视为空值，展示为 --） */
    price?: string | number | null
    /** 前置符号 */
    type?: string
    /** 是否显示小数部分 */
    double?: boolean
    /** 后置单位 */
    unit?: string
    /** 价格单位 */
    priceUnit?: string
    /** 符号样式 */
    signStyle?: string
    /** 是否使用科技计数法 */
    isThousand?: boolean
  }

  const props = withDefaults(defineProps<Props>(), {
    showSign: true,
    price: '',
    type: '',
    double: false,
    unit: '',
    priceUnit: 'fen',
    signStyle: '',
    isThousand: false
  })

  /** 是否为空值 */
  const isEmpty = computed(() => props.price === '' || props.price === null || props.price === undefined)

  /** 价格（空值或非法数字时为 NaN） */
  const pix = computed(() => {
    if (isEmpty.value) return NaN
    return props.priceUnit === 'fen' ? Number(props.price) / 100 : Number(props.price)
  })

  /** 整数部分 */
  const int = computed(() => {
    if (isNaN(pix.value)) return '--'
    const absPix = Math.abs(pix.value)
    const intStr = absPix.toFixed(2).split('.')[0]
    return props.isThousand ? ToThousandFilter(intStr) : intStr
  })

  /** 小数部分 */
  const decimal = computed(() => {
    if (isNaN(pix.value)) return ''
    const absPix = Math.abs(pix.value)
    let num: string = absPix.toFixed(2).split('.')[1]
    if (!props.double) {
      if (Number(num) === 0) return ''
      if (Math.floor(Number(num) / 10) === Number(num) / 10) num = (Number(num) / 10).toString()
    }
    return '.' + num
  })
</script>

<style lang="scss" scoped>
  .price {
    display: inline-flex;
    align-items: baseline;
    justify-content: flex-start;
  }
</style>
```


### 使用

```vue
<!-- 存的是「分」，展示 1,234,567.89 元 -->
<Price :price="123456789" double is-thousand />

<!-- 带标签与单位 -->
<Price :price="9990" type="现价" unit="/年" />

<!-- 空值 -->
<Price :price="null" />
```

## InputPrice（输入）

### InputPrice 的 Props

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `v-model` | `number \| string` | `''` | **实际值（分）** |
| `ratio` | `number` | `100` | 分 ↔ 元换算比例 |
| `size` | `'' \| 'default' \| 'small' \| 'large'` | `'default'` | 输入框尺寸 |
| `max` | `number` | `Infinity` | 允许输入的最大值（**元**） |
| `min` | `number` | `0` | 允许输入的最小值（**元**） |
| `disabled` | `boolean` | `false` | 禁用 |

### 输入规则

- 输入框里显示的是**元**（`v-model / ratio`），写回 `v-model` 的是**分**。
- 提交（change/blur）时：空值或只有 `-` / `.` / `-.` → 置空；非法数字 → 回退上一次有效值；超范围 → 夹到 `min` / `max`。
- 外部给 `v-model` 赋值时（含首次回显），会反算出元并同步到输入框。

### InputPrice 的源码

```vue
<template>
  <el-input
    v-model="displayValue"
    type="number"
    :disabled="disabled"
    clearable
    :size="size"
    :step="0.01"
    :min="min"
    :max="max"
    @blur="handleCommit"
    @change="handleCommit"
    @keyup.enter="handleCommit">
    <template
      v-if="slots.prefix"
      #prefix>
      <slot name="prefix" />
    </template>
    <template
      v-if="slots.suffix"
      #suffix>
      <slot name="suffix" />
    </template>
    <template
      v-if="slots.prepend"
      #prepend>
      <slot name="prepend" />
    </template>
    <template
      v-if="slots.append"
      #append>
      <slot name="append" />
    </template>
  </el-input>
</template>

<script lang="ts">
  export default {
    name: 'InputPrice'
  }
</script>

<script lang="ts" setup>
  import { useDivide, useMulti } from '@/hooks/useCalc'

  /** 实际值 */
  const modelValue = defineModel<number | string>({ default: '' })

  interface Props {
    /** 分↔元转换比例，默认 100（1元=100分） */
    ratio?: number
    /** 尺寸 */
    size?: '' | 'default' | 'small' | 'large'
    /** 允许输入的最大值（元单位） */
    max?: number
    /** 允许输入的最小值（元单位） */
    min?: number
    /** 禁用 */
    disabled?: boolean
  }
  const props = withDefaults(defineProps<Props>(), {
    ratio: 100,
    size: 'default',
    max: Infinity,
    min: 0,
    disabled: false,
  })

  const slots = useSlots()

  /** 显示值 */
  const displayValue = ref<string>('')

  watch(
    modelValue,
    val => {
      if (val === '' || val === null || val === undefined || isNaN(Number(val))) {
        displayValue.value = ''
      } else {
        displayValue.value = String(useDivide(Number(val), props.ratio))
      }
    },
    { immediate: true }
  )

  const handleCommit = () => {
    const raw = displayValue.value.trim()
    if (raw === '' || raw === '-' || raw === '.' || raw === '-.') {
      modelValue.value = ''
      return
    }
    const num = Number(raw)
    if (isNaN(num)) {
      // 非法输入，回退到上一次有效值
      modelValue.value = modelValue.value
      return
    }
    const clamped = Math.min(Math.max(num, props.min), props.max)
    displayValue.value = String(clamped)
    modelValue.value = useMulti(clamped, props.ratio)
  }
</script>

<style lang="scss">
  /* 隐藏 el-input type=number 的原生上下箭头 */
  .el-input__inner {
    -moz-appearance: textfield;

    &::-webkit-outer-spin-button,
    &::-webkit-inner-spin-button {
      -webkit-appearance: none;
      margin: 0;
    }
  }
</style>
```

### InputPrice 的使用

```vue
<template>
  <el-form-item label="金额（元）">
    <InputPrice v-model="form.amount" :max="maxAmount" :size="'default'" />
  </el-form-item>
</template>

<script lang="ts" setup>
  /** amount 存的是分：123456 表示 1234.56 元 */
  const form = reactive({ amount: 0 })
  const maxAmount = 1_000_000 // 元
</script>
```

## 注意事项

1. **单位不要混**：`Price.price` 与 `InputPrice` 的 `v-model` 都是**分**；`InputPrice` 的 `min` / `max` 是**元**。
2. `priceUnit` 传非 `'fen'`（如 `'yuan'`）时，`Price` 直接按元展示，不会除以 100。
3. `Price` 是纯展示组件，没有事件；需要可编辑时用 `InputPrice`。
4. 列表里大量金额展示时，`is-thousand` 与 `double` 建议在全站统一，避免出现「一半带小数、一半不带」。
