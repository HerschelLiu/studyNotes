#### 迁移最新版本导致报错问题兼容

##### [postcss] ENOENT: no such file or directory, open '~bpmn-js/dist/assets/diagram-js.css'

**bpmn-js 在 v18 里把 `diagram-js.css` 合进了 `bpmn-js.css`，单独的文件已经不存在了。**

在 v11.1.0 里，标准引入是两条：

```js
import 'bpmn-js/dist/assets/diagram-js.css';
import 'bpmn-js/dist/assets/bpmn-js.css';
```

从 v11 升到 v18 是跨了好几个大版本，除了样式这条，其他可能的 breaking changes 也建议留意一下：

- **API 层面**：`BpmnModeler` / `BpmnViewer` 的核心 API 大体兼容，但 `create/append anything` 等高级功能被拆到了独立模块。
- **properties panel / element templates** 的样式路径也调整过（`dist/assets/properties-panel.css` 已不再随包发布，改由 `bpmn-js-element-templates` 提供）。
- 如果用了 `dmn-js`、`bpmn-js-properties-panel` 等配套包，它们的版本也要一起升级到配套的大版本。

**如果还报错**，查找`~bpmn-js/dist/assets/diagram-js.css`，把前边~去掉



##### 浏览器报错`Uncaught SyntaxError: The requested module '/src/components/vform/VFormDesigner.umd.min.js' does not provide an export named 'default' (at main.ts:48:8)`

UMD 格式文件没有 ES Module 的 default 导出，不能用 import 语法直接引入。需要通过 <script> 标签加载到 window 上，再从 window 获取。

并且**若依的工作流库使用的是vue2的，所以vue3应该用支持的版本**



##### `index.vue:306 Uncaught ReferenceError: process is not defined at Proxy.data (index.vue:306:14)`

Vite 项目中环境变量是 `import.meta.env.VITE_APP_BASE_API ，不`是 `process.env.VUE_APP_BASE_API `（那是 Vue CLI 的写法）。
