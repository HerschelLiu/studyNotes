# 常用快捷键

> VS Code 快捷键，macOS 键位为主（括号内为 Windows / Linux 写法）。

## 默认快捷键

| 功能 | 快捷键 |
| --- | --- |
| 整理 import 语句 | `shift + option + o` |
| 打开文件 / 文件夹 | `cmd + o`（系统打开文件）、`cmd + p`（VS Code 内打开文件） |
| 向上 / 向下复制 | `shift + option + ↑ / ↓` |
| 删除当前行 | `cmd + shift + k`、`cmd + x` |
| 调出控制台 | `ctrl + ~`、`cmd + j` |
| 在开 / 闭括号之间跳转 | `cmd + shift + \` |
| 跳到文件开头 / 结尾 | `cmd + ↑ / ↓` |
| 移动到单词前面 / 后面 | `option + ← / →` |
| 移动到当前行最前 / 最后 | `cmd + ← / →` |
| 切换文件 | `ctrl + tab` |

## 折叠展开

- **折叠当前区域**：`ctrl + shift + [`（Windows / Linux）或 `cmd + option + [`（Mac）
- **展开当前区域**：`ctrl + shift + ]`（Windows / Linux）或 `cmd + option + ]`（Mac）
- **折叠所有区域**：`ctrl + k ctrl + 0`（Windows / Linux）或 `cmd + k cmd + 8`（Mac）
- **折叠所有区域**：`ctrl + k ctrl + j`
- **折叠所有块注释**：`cmd + k cmd + 、`（Mac）

## 修复

- Mac：`cmd + .`

## 建议

- Mac：`cmd + i` 有冲突，已改为 `ctrl + cmd + option + i`
