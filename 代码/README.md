## 维护约定

1. 每篇文档以 `#` 一级标题开头，标题与文件名一致或更贴切。
2. 有对应代码文件的目录（`前端/组件库`、`前端/hooks`、`前端/若依`、`前端/typescript/typings`），文档代码块按实际文件对齐，源码区与文件保持一致。
3. 代码块尽量标语言（`bash` / `ts` / `vue` / `css` / `json`…）；纯输出、目录树、混排片段可标 `text` 或不标。
4. 新内容放进对应分类目录，不再新增「其他」「杂项」「笔记」这类兜底目录。
5. 300 行以上的文档加 `## 目录`（用锚点链接），标题层级不跳级（H1 → H2 → H3）。
6. 文件名避免 ASCII 括号、`#`、`?` 等会破坏 Markdown 链接的字符，需要括号时用全角 `（）`。
7. 新增 / 删除 / 移动文件后，重新生成根目录 `README.md` 的全库索引（目录树 + 可点击链接）。
